# Agentic Systems


## Glossary 
* **Agent** - Union of long term history, short term current state, and an inference platform.  Agents can take multiple forms.
* **Communication Channel** - A mechanism for transporting inputs and outputs between a specific set of agents and users on a spefific communication system.
  * Examples from Slack:
    * A direct message between the user and a bot connection
    * A direct message between a bot and two users.
    * A public channel
* **Communication System** - A system which allows for human to agent interaction.  Users will have a unique identity within these systems.  Examples include:
  * Slack
  * Telegram
  * Matrix
  * E-mail
  * Web User Interface
* **Gateway** - A system responsible for the coordination of multiple users and agents within a system.
* **Large Language Model** (LLM) – Given a specific input will infer the most likely output.  Due to emergent behavior of the training produces mostly coherent text.
* **LLM Provider** – A system to run model inference due to the current hardware constraints and limitations.
* **User** - A real user or person we are interacting with
